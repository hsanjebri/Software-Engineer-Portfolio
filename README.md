# Hassan Jebri | Software Engineer Portfolio 🚀

A premium, high-performance developer portfolio built with a focus on smooth animations, 3D graphics, and clean architecture. This project showcases my journey as a Software Engineer, highlighting my work in Full-Stack development and AI/Machine Learning.

## ✨ Features

- **Smooth Experience**: Powered by **Lenis** for buttery-smooth scrolling and **GSAP** for industry-standard animations.
- **3D Interactive Elements**: Integrated **Three.js** and **React Three Fiber** for immersive visual components.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **Dynamic Configuration**: All content (projects, experience, tech stack) is easily managed via a single `config.ts` file.

## 🛠️ Tech Stack

- **Core**: React 18, TypeScript, Vite
- **Animations**: GSAP (ScrollTrigger, Flip), Lenis
- **3D Engine**: Three.js, React Three Fiber, Rapier Physics
- **Styling**: Vanilla CSS (Modern CSS variables)
- **Deployment**: Vercel ready

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd developer-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 📁 Project Structure

- `src/components/`: Modular React components.
- `src/config.ts`: The central source of truth for all portfolio data.
- `src/context/`: Global state management for loading and theme.
- `src/styles/`: Global and component-specific styles.
